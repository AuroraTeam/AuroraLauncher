# План работ

## Единый формат путей файлов в API

Статус: запланировано. Добавлено 2026-11-06.

GitHub: [Привести пути файлов в API к единому формату #97](https://github.com/AuroraTeam/AuroraLauncher/issues/97).

Сервер должен отдавать пути файлов с разделителем `/` независимо от своей ОС.
Сейчас `ClientsManager.hashFile()` только удаляет префикс `StorageHelper.clientsDir`:
на Windows в манифесте `/updates` остаются обратные слеши. Частичная нормализация
в Updater уже есть, но она не охватывает все операции с путями.

Порядок работ:

1. Проверить существующую нормализацию на сервере и в лаунчере, чтобы использовать
   единое правило без дублирования преобразований.
2. Определить контракт путей API: разделитель `/`, корень отсчёта и наличие
   начального `/`. Согласовать его с `clientDir` и `gameJar`.
3. Нормализовать пути при формировании серверного манифеста. Проверить остальные
   поля API, содержащие пути, на соответствие тому же контракту.
4. Проверить использование путей лаунчером: сравнение игрового JAR, скачивание,
   построение URL, `update`/`updateVerify`/`updateExclusions`, очистка и Watcher.
   Определить необходимость совместимости с манифестами старых серверов.
5. После согласования контракта пересмотреть локальный `normalizePath` в Updater:
   оставить только необходимые правила сравнения.

Критерии готовности:

- Сервер на Windows и сервер на Linux возвращают одинаковый формат путей.
- Лаунчер на обеих ОС правильно скачивает и проверяет один и тот же клиент.
- Проверены вложенные пути, нестандартный `gameJar`, исключения и пользовательские
  файлы; очистка не затрагивает файлы вне нужного каталога.
- Формат и решение о совместимости описаны в документации и покрыты тестами.

Окно настроек клиентов пока отложено.
